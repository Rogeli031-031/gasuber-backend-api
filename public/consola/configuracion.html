ID tarjeta (Raspberry)

Asigna RPI-001…040 al activo seleccionado (estación, almacén o autotanque). Vacío = sin asignar.

Tripulación

Un chofer y un ayudante por autotanque. Cada empleado solo en un número.

Configuración

Asigna tarjetas RPI a estaciones, almacenes o autotanques. Esta sección usa los mismos endpoints y la misma API key que Telemetría.

Asignación de tarjetas (selecciona Planta → PDV → activo)

Al asignar una tarjeta, el backend permite que esa Raspberry envíe telemetría GPS al activo.

Listo para usar

Selecciona en la barra lateral y usa Guardar tarjeta. No hay polling ni mapa en esta sección para evitar carga extra.
